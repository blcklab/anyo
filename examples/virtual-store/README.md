# Virtual store example

From the repository root:

```bash
npm install ../blcklab-sekai64-0.7.0-rc.1.tgz
npm run build
python -m http.server 4173
```

Open `http://localhost:4173/examples/virtual-store/`.

The example demonstrates multiple rooms, two floors, stairwell cutouts, prefabs, repeated fixtures, wall text, interactions, trigger zones, touch controls, and live `$bind` data updates.
