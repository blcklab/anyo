# Universal Geometry Showcase

Step 11 acceptance world for the universal geometry freeze. The scene deliberately builds eight semantically different forms without adding semantic geometry kinds to Anyo Core:

- spiral tower — reusable helix + sweep + profile stations;
- curved bridge — reusable arc + sweep;
- procedural tree-like form — loft trunk + tapered sweep branch mirrored through the operator pipeline;
- twisted sculpture — profile extrusion + twist + taper + bend;
- arched doorway — generic CSG subtraction plus a raw indexed-mesh keystone;
- rocky formation — sphere + reusable scalar-field displacement;
- pipe/cable network — multiple reusable curves + sweep;
- procedural pavilion — baked array columns + lofted roof.

The world is intentionally renderer-neutral. Sekai64 receives only ordinary geometry resources. This milestone is a proof fixture, not a new semantic feature layer.
